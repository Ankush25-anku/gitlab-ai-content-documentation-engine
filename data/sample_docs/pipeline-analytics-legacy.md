# CI/CD analytics

The CI/CD analytics page shows pipeline success rate and duration charts for the last 30 days.

## View CI/CD analytics

Go to **Analyze > CI/CD analytics**. The charts show successful and failed pipelines. Cache statistics are not available on this page.
